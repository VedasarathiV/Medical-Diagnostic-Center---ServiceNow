# 🏥 Medical Diagnostic Center – ServiceNow

## 📌 Overview

**Medical Diagnostic Center** is a healthcare workflow application developed using the **ServiceNow Platform** to simplify and automate the management of diagnostic test appointments in hospitals and medical diagnostic centers.

The system provides a centralized digital platform where users can explore available diagnostic tests, book appointments, track appointment status, and access their laboratory reports.

The project focuses on replacing manual and fragmented diagnostic-center processes with a more organized, transparent, and user-friendly digital workflow.

---

## 🎯 Project Objective

The main objective of this project is to digitize the diagnostic test management process using ServiceNow.

The application is designed to:

- Simplify diagnostic test booking
- Reduce manual appointment management
- Provide clear appointment status tracking
- Improve visibility for diagnostic-center staff
- Organize test and appointment information
- Provide patients with easier access to their diagnostic services
- Maintain a centralized system for appointment and test management

---

## ❗ Problem Statement

Many hospitals and diagnostic centers still depend on manual processes, phone calls, spreadsheets, or disconnected systems for managing diagnostic test appointments.

This can result in:

- Long waiting times
- Appointment conflicts
- Difficulty tracking test bookings
- Limited visibility into appointment status
- Manual coordination between patients and staff
- Difficulty accessing diagnostic reports
- Increased administrative workload

The **Medical Diagnostic Center – ServiceNow** project addresses these challenges by providing a centralized digital solution for managing the diagnostic testing lifecycle.

---

## 💡 Proposed Solution

The system provides an easy-to-use portal where users can interact with diagnostic-center services digitally.

The application allows users to:

1. View available diagnostic tests
2. Select the required test
3. Book a diagnostic appointment
4. Select the preferred date and time
5. View appointment details
6. Track appointment status
7. View payment-related information
8. Cancel eligible appointments
9. Access laboratory reports

Diagnostic-center staff can monitor appointment information and manage the appointment lifecycle through a centralized interface.

---

# ✨ Key Features

## 🧪 Diagnostic Test Services

Users can explore diagnostic tests available through the medical diagnostic center.

Each test can contain information such as:

- Test name
- Test category
- Description
- Appointment availability
- Test price
- Booking information

---

## 📅 Appointment Booking

Patients can book diagnostic test appointments through the application.

Appointment information can include:

- Appointment ID
- Diagnostic test
- Appointment date
- Appointment time
- Test category
- Price
- Payment status
- Appointment status

---

## 📊 Appointment Management

The application provides a centralized appointment dashboard to make appointment tracking easier.

Appointments can be filtered based on their current status, including:

- **Pending**
- **Confirmed**
- **Completed**

The interface also displays summary information such as:

- Total appointments
- Pending appointments
- Confirmed appointments
- Completed appointments

---

## 🔎 Appointment Search & Filtering

Users can quickly find appointments using search and filtering options.

This makes it easier to manage a large number of diagnostic test bookings.

---

## 👁️ Appointment Details

Users can view complete information regarding a selected appointment through the **View Details** option.

This improves transparency and makes important appointment information easily accessible.

---

## ❌ Appointment Cancellation

Eligible appointments can be cancelled directly through the application.

This simplifies appointment management and reduces the need for manual communication with the diagnostic center.

---

## 💳 Payment Status

The appointment interface displays payment-related information so that users and administrators can easily identify the payment status associated with an appointment.

---

## 📄 Lab Reports

The application includes a dedicated **Lab Reports** section where users can access diagnostic reports associated with their medical tests.

This helps keep diagnostic information organized within the same platform.
